# Raven App Control 1.2.2

- Matches the shared Raven About layout with a 480 dp width where it fits, a centered 72 dp icon, and consistent type sizes and spacing.
- Uses 20 dp of side clearance on narrower screens and lets the height follow the content.

The exact signed build passed About checks on Odin 3 with Android 15. All content, including License and Close, fit without scrolling in portrait and landscape. The License link opened in both orientations.
