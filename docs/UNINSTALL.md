# Removal

1. In Disabled, re-enable apps you want available. Turn on Show system apps to review disabled system apps.
2. Confirm those apps work normally.
3. Uninstall Raven App Control through Android.

Raven installs no persistent root daemon, boot hook or background watcher. Its app preferences are removed on uninstall; disabled package states are stored by Android and are not automatically reversed. See [Recovery](RECOVERY.md) if Raven has already been removed.
